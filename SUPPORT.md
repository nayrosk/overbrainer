# Getting help

- Start with the [README](README.md) and the guides in [docs](docs): configuration, pipeline, training, Runpod and the terminal UI.
- Found a bug or want a feature? Open an issue with one of the [issue forms](https://github.com/nayrosk/overbrainer/issues/new/choose).
- Found a vulnerability? Follow the [security policy](SECURITY.md) and report it privately.

overbrainer is maintained on a best-effort basis; there is no guaranteed response time outside security reports.
